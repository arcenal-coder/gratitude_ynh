# Gratitude

Application propriétaire de reconnaissance interne pour YunoHost. Elle est indépendante de Listen Leon et ne communique avec aucun de ses services.

## Version 0.2 — interface web

- Tableau de bord, envoi d'un merci, mur personnel et mur commun adaptés au mobile.
- Connexion par SSO YunoHost, base SQLite locale et annuaire auto-amorcé depuis les membres connectés.
- Entités internes, mercis signés ou anonymes, modération, challenges, candidatures et vote unique.
- API REST versionnée sous `/api/v1` pour une future application mobile.
- Paquet YunoHost : installation, mise à niveau, sauvegarde et restauration.

Consulter le [CDC](docs/CDC-gratitude-yunohost-v0.1.md) et la [documentation API](docs/API-v1.md).
