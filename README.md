# Gratitude

Application propriétaire de reconnaissance interne pour YunoHost. Elle est indépendante de Listen Leon et ne communique avec aucun de ses services.

## État du premier jalon

- API REST versionnée sous `/api/v1`.
- Connexion par SSO YunoHost et base SQLite locale.
- Entités internes, mercis signés ou anonymes, modération et challenges.
- Paquet YunoHost : installation, mise à niveau, sauvegarde et restauration.

Consulter le [CDC](docs/CDC-gratitude-yunohost-v0.1.md) et la [documentation API](docs/API-v1.md).
